# ARGUS Frontend

Next.js dashboard for ARGUS. See the repository root [README](../README.md)
for project overview and setup instructions.

```bash
npm install
npm run dev   # http://localhost:3000
```

Phase 01 ships a landing page and the app shell. Directory boundaries:
`app/` (routes), `components/` (UI), `lib/` (config/utilities), `hooks/`
(React hooks), `types/` (shared types). Investigation features arrive in
later phases.
